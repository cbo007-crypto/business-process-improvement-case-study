# Business Process Improvement Case Study

# Overview

This portfolio project presents a business process improvement case study focused on the small business account onboarding process. The objective was to identify operational bottlenecks, analyze root causes, and propose process improvements using business analysis and process improvement methodologies.

# Skills Demonstrated

* Business Process Mapping
* Root Cause Analysis (5 Whys)
* Fishbone (Ishikawa) Diagram
* Process Improvement
* KPI Development
* Workflow Analysis
* Executive Presentation Design
* Microsoft PowerPoint

# Project Summary

The case study evaluates a current-state onboarding process, identifies key operational challenges, and recommends a future-state workflow designed to reduce onboarding time, improve efficiency, and enhance the customer experience.

# Deliverables

* PowerPoint presentation
* Fishbone diagram
